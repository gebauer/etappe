Where the photos and their captions come from. A folder on the server holds the images plus one photos.json manifest: per entry a file name, place, region, optional coordinates and a month. The overlay renders only the fields present — no placeholder text, no Unknown location. One photo per sign-in visit, crossfading every 7 s while the page stays open, caption swapping with it; the four ticks are the position in that rotation. Sourcing these from the user's own finished trips is a separate feature request, not this design.
